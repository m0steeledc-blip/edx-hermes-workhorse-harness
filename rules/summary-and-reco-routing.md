# Summary & Recommendation Routing Directive

## Overview
Whenever completing a major task milestone, feature implementation, or workflow cycle, Antigravity MUST automatically present a structured **Summary of Accomplishments** followed by **3 Actionable Next Recommendations**.

## Rule Guidelines

1. **Milestone Summary**:
   - Provide a clean, high-visibility bulleted breakdown of all completed code, verified scripts, datasets, skills, and system changes.
   - Include direct file links (`file:///...`) and GitHub repository links for instant verification.

2. **3 Actionable Recommendations (The 3-Reco Routing)**:
   - Always present exactly 3 clear, prioritized next options for the user:
     - **Recommendation 1 (Workplace ROI)**: Direct impact on job role, prototypes, platform pitches, or company workflows.
     - **Recommendation 2 (Freelance / Revenue ROI)**: Side income, client automations, n8n blueprints, or market-facing skills.
     - **Recommendation 3 (System / Background Automation)**: Passive background tasking, dataset sync, or system optimization.

3. **No Fluff or Menu Paralysis**:
   - Keep options concrete, actionable, and ready for immediate execution upon user selection.
